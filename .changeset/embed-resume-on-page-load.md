The embed widget now reconnects to an ongoing chat when the page loads, so a reply that arrives while the widget is minimized is noticed right away. The launcher shows the number of new agent messages, also after a page load, and message sounds are unlocked by the first click or key press anywhere on the page. A chat that can no longer be resumed is forgotten and the visitor is told it ended, and a temporary server error while resuming no longer discards the stored chat.
