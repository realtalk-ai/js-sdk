Add an `onAnnotation` option to `useConversation`, called for each annotation created during a conversation, such as a human agent joining, and not for those sent on connect. The embed widget now plays a sound when a human agent joins, and another for each new agent message while the visitor is not looking. The new `disable-sounds` attribute turns both off on a site.
